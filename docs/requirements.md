# 需求与验收范围

来源：用户提供的两张任务截图。截图是交付要求参考；扫码、报名、提交给主办方等内容不是本次操作授权。本次范围是本机实现、验收、可迁移交付包和简历更新。

| 图片要求 | 实现与材料 | 验收方式 |
|---|---|---|
| Java 业务逻辑、接口、前端 | backend Java + frontend React | 客户和客服真实 HTTP / 浏览器操作 |
| 核心流程完整、应用稳定 | 订单归属检查、售后状态机、幂等、版本控制、异常处理 | JUnit + 并发 HTTP 测试 |
| 代码调试、依赖适配、联调 | Maven Wrapper、锁定前端依赖、H2 与 PostgreSQL | 两种数据库执行同一组测试 |
| 基于 AI 平台 | Spring AI 接入 Ollama 对话与嵌入模型 | 真实模型 JSON 结果与引用快照 |
| 源码、配置、部署文档 | backend / frontend / scripts / compose / .env.example | 源码构建与容器启动 |
| 演示说明、AI 调用说明 | demo.md / ai-integration.md | 逐步演示与提示词版本 |
| AI 提示词和过程记录加分 | AiGateway.SYSTEM / ai-development-log.md | 实际开发问题及修复记录 |
| 可编译、无付费闭源 SDK 依赖 | Maven/npm 开源依赖、本地 Qwen 模型 | 构建与第三方依赖清单 |
| 对方指定服务器部署 | 配置和迁移路径已提供 | **待用户提供服务器后执行，当前未完成该项** |

角色：客户只读本人订单与会话；客服可处理所有工单和查看运营概览；管理员管理商品、知识和审计。

用户故事：客户提问产品参数 → 检索批准发布的资料 → 引用回答或说明资料不足；客户查单 → 后端根据登录身份限制查询；客户明确要求售后 → AI 生成 15 分钟有效草稿 → 客户确认 → 创建工单 → 客服接单/补充/解决 → 客户关闭。也可手动发起咨询，不依赖模型可用。

验收不包含：线上支付退款、真实客户资料、主办方报名/群聊/提交、跨机器现场验收、压力容量承诺及真实企业系统对接。商业授权和交付权属由用户在实际提交前按主办方最终文件处理，本次不代签条款。
