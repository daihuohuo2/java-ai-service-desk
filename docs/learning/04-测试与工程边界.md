# 第四课：测试和工程边界

## Maven 三个模块

```text
desk-app    控制器、服务实现、Mapper/Repository、外部模型、缓存、任务、启动类
   ↓
desk-domain 实体、DTO、业务接口、纯规则
   ↓
desk-common 异常、响应、分页、CSV、校验基础设施
```

箭头表示依赖。domain 不依赖 app，所以业务接口不能引用 Controller 或数据库 Repository；common 不引用业务实体。Maven 会先构建被依赖的模块，最后把 common/domain 打入 desk-app 的可执行 JAR。模块是编译边界，部署仍是一个 Spring Boot 进程。

entity 使用 MyBatis-Plus 映射注解，DTO 使用 Jackson 注解，因此 domain 不是完全框架无关的纯领域模型。这是为了展示常见 Java 工程形态；纯业务规则 TicketPolicy/KnowledgeText/CitationPolicy 仍可不启动 Spring 运行。

## 纯单测与集成测试的区别

OrderServiceTest 的 `@ExtendWith(MockitoExtension.class)` 创建 Mockito 环境；`@Mock OrderMapper` 是替身，`@InjectMocks OrderServiceImpl` 是真实待测类。when 指定替身返回值，assert 验证业务结果，verify 检查依赖是否被正确调用。`verifyNoInteractions` 可验证非法输入在访问数据库之前被拦截。

它不证明 SQL 能在 PostgreSQL 执行，也不证明事务隔离正确。DeskIntegrationTest/FullstackIntegrationTest 启动 Spring 和数据库，才验证真实映射、事务及接口。MiddlewareIntegrationTest 连接真实 Redis/RabbitMQ，但模型仍是 Mock。浏览器测试连接真实后端，但关闭模型以稳定验证页面流程。真实模型验收单独运行。

```powershell
# 只执行隔离单测；不启动 Spring 应用，不连接数据库和模型
.\backend\mvnw.cmd -B -ntp -f backend/pom.xml -Punit test
# 只观察一个类；聚合构建会自动构建所需模块
.\backend\mvnw.cmd -f backend/pom.xml -Punit "-Dtest=OrderServiceTest" test
# H2 的整体回归并生成应用 JAR
.\backend\mvnw.cmd -B -ntp -f backend/pom.xml verify
# 两种真实数据库、Redis、RabbitMQ
.\scripts\run-integration.ps1
```

## 事务、幂等和版本

TicketServiceImpl.create 在事务里先锁当前用户，再按 owner:key 查找旧请求；同 key 同内容返回原工单，同 key 不同内容返回 409。工单、事件和审计在同一事务中提交。数据库唯一约束提供最后一道保护。

update 先锁工单，再验证调用者和 version；成功后 version+1。行锁保证并发更新串行检查，版本号让持有旧页面的用户收到冲突，而不是覆盖他人的修改。TicketPolicy.nextStatus 是纯规则，SQL 锁放在 TicketRepository。

confirm 先锁用户再锁草稿，与创建工单的锁顺序一致。这里同一个对象内部调用 create 不会再次经过 Spring 代理，但 confirm 本身已经有事务，因此仍在同一事务内执行。不要把这一点误记成“同类内部调用的 @Transactional 总会生效”。

ProductServiceImpl 在活动事务中绕过共享缓存，防止未提交值进入 Redis。缓存 key 使用数据库 revision，更新成功后递增；Redis 故障不会使旧 revision 的 key 再次成为当前值。

IndexJobProcessor 通过条件 UPDATE 抢占任务，lease_token 隔离不同消费者；心跳续租，过期可重新认领，失败有次数上限。这些行为的正确性需要数据库和并发测试，不能只 Mock 所有依赖后宣布成立。

## 练习

先让 page=0 的测试失败，再恢复参数校验使它通过。然后给 OrderServiceTest 增加非法状态用例，断言 HTTP 对应业务状态为 400 且 Mapper 没被调用。最后打开集成测试，看同一个约束如何通过 MockMvc 验证。不要为了增加数量写“getter 返回 setter 写入值”式测试。
