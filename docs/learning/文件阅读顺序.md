# 按文件阅读：每个模块负责什么

所有路径相对于项目根目录。下面先给学习顺序，再列出余下文件；“后读”不表示不重要，而是避免一开始同时处理 Spring、SQL、权限和 AI。

| 顺序 | 文件 | 负责的功能 | 看懂的标准 |
|---|---|---|---|
| 1 | [FullstackBasics.java](../../learning/FullstackBasics.java) | 不依赖框架的对象、接口、泛型、分页、异常实验 | 能自己改数据并解释输出 |
| 2 | [OrderResponse.java](../../backend/src/main/java/cn/liuyang/desk/OrderResponse.java) | 一条订单的数据类型与 JSON 字段映射 | 区分对象、字段和 Map |
| 3 | [PageResponse.java](../../backend/src/main/java/cn/liuyang/desk/PageResponse.java) | 通用分页结果及边界校验 | 能计算 page/size/offset/pages |
| 4 | [OrderService.java](../../backend/src/main/java/cn/liuyang/desk/OrderService.java) | 订单查询、参数检查、售后资格判断 | 解释每个方法的调用者与返回值 |
| 5 | [OrderMapper.java](../../backend/src/main/java/cn/liuyang/desk/OrderMapper.java) | MyBatis SQL 与对象映射 | 找到所有 owner_id 参数约束 |
| 6 | [OrderController.java](../../backend/src/main/java/cn/liuyang/desk/OrderController.java) | 订单 HTTP 接口 | 从 URL 对应到 Java 参数 |
| 7 | [Actor.java](../../backend/src/main/java/cn/liuyang/desk/Actor.java) | 从当前认证信息取得用户和角色 | 不把页面传参当身份 |
| 8 | [DeskApplication.java](../../backend/src/main/java/cn/liuyang/desk/DeskApplication.java) | Java 应用与调度启动入口 | 明白其他类由 Spring 管理 |
| 9 | [ProductRepository.java](../../backend/src/main/java/cn/liuyang/desk/ProductRepository.java) | JdbcTemplate 查询/保存商品和目录版本 | 与 MyBatis 对比 |
| 10 | [ProductInput.java](../../backend/src/main/java/cn/liuyang/desk/ProductInput.java)、[ProductResponse.java](../../backend/src/main/java/cn/liuyang/desk/ProductResponse.java) | 商品输入校验、输出类型 | 区分请求与数据库结果 |
| 11 | [ProductService.java](../../backend/src/main/java/cn/liuyang/desk/ProductService.java)、[ProductController.java](../../backend/src/main/java/cn/liuyang/desk/ProductController.java) | 商品业务事务与接口 | 找到事务中的三次写入 |
| 12 | [TicketService.java](../../backend/src/main/java/cn/liuyang/desk/TicketService.java) | 建单、状态流转、版本冲突、幂等、草稿确认 | 追踪一张工单完整生命周期 |
| 13 | [BusinessController.java](../../backend/src/main/java/cn/liuyang/desk/BusinessController.java) | 工单写接口、概览与审计；保留旧列表接口 | 理解它不再处理订单/商品接口 |
| 14 | [TicketQueryService.java](../../backend/src/main/java/cn/liuyang/desk/TicketQueryService.java)、[TicketQueryController.java](../../backend/src/main/java/cn/liuyang/desk/TicketQueryController.java)、[CsvExport.java](../../backend/src/main/java/cn/liuyang/desk/CsvExport.java) | 工单服务端分页、筛选、带授权的 CSV 导出 | 能解释用户隔离和公式转义 |
| 15 | [Store.java](../../backend/src/main/java/cn/liuyang/desk/Store.java) | 原业务模块共用 JDBC、JSON、ID、审计辅助 | 区分通用辅助与业务规则 |
| 16 | [ApiException.java](../../backend/src/main/java/cn/liuyang/desk/ApiException.java)、[ApiAdvice.java](../../backend/src/main/java/cn/liuyang/desk/ApiAdvice.java) | 业务异常与 HTTP 错误转换 | 区分 400/401/403/404/409 |
| 17 | [AuthController.java](../../backend/src/main/java/cn/liuyang/desk/AuthController.java)、[SecurityConfig.java](../../backend/src/main/java/cn/liuyang/desk/SecurityConfig.java) | 登录、Cookie 会话、CSRF、角色访问规则 | 能在浏览器 Network 中找对应请求 |
| 18 | [SeedData.java](../../backend/src/main/java/cn/liuyang/desk/SeedData.java) | 虚构演示数据与生产模式启动约束 | 不将演示密码用于正式环境 |

缓存、异步和 AI 的阅读顺序：

| 顺序 | 文件组 | 职责 |
|---|---|---|
| 19 | CatalogCache → NoCatalogCache → RedisCatalogCache | 接口、多态、默认不缓存、Redis 版本键/TTL/失败回源 |
| 20 | IndexJob → IndexJobController → IndexJobService | 任务结果类型、管理员接口、任务落库与幂等 |
| 21 | IndexJobDispatcher → IndexQueueConfiguration | 定时扫描、本地消费或 RabbitMQ 投递、队列声明/监听 |
| 22 | IndexJobProcessor | 原子抢占、租约续期、消费去重、重试和失败恢复 |
| 23 | KnowledgeController → KnowledgeService | 知识维护、分段、向量化、混合检索 |
| 24 | ChatController → ChatService | HTTP/SSE、会话归属、模型计划转业务行为 |
| 25 | AiGateway → HttpClients | Spring AI/Ollama 调用、模型超时、短引用映射、网络超时 |
| 26 | learning/ConcurrencyLab.java | 用纯 Java 重现并发槽、资源释放、超时和协作取消 |

后端这些类都位于 `backend/src/main/java/cn/liuyang/desk/`。新模块使用明确类型，旧工单与知识模块仍有 Map，保留为后续逐模块重构练习。

每天只选一条调用链，记录“谁调用、输入是什么、执行什么、返回什么、失败时如何处理”。旧版学习笔记保留作改造前对照，当前代码以本文件和全栈学习路线为准。
